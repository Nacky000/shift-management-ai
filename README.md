# ShiftBot

**LINE × OpenAI による自然言語ベースのシフト管理支援システム**

ShiftBot は，飲食店のシフト提出や変更，欠勤・遅刻連絡などを，LINE 上の自然な文章から処理するシフト管理支援システムである．

OpenAI API を用いてメッセージを構造化し，内容に応じた処理を実行することで，スタッフの入力負担と管理者の転記作業の削減を目指す．

現在は，LINE Bot と AI によるメッセージ解析，処理の振り分け，Google スプレッドシートとの連携を中心に開発している．

## 背景・目的

飲食店のシフト管理では，スタッフからの希望提出，提出後の変更，欠勤・遅刻連絡など，さまざまな情報を管理者が確認し，シフト表へ反映する必要がある．

こうした情報を手作業で整理・転記することは，スタッフと管理者双方の負担につながる．また，入力形式が統一されていない場合，内容の確認や情報の整理にも手間がかかる．

ShiftBot では，普段使い慣れている LINE を入力インターフェースとして活用し，自然言語による連絡を構造化されたデータへ変換することで，シフト管理業務の効率化を目指す．

## 主な機能

### 1. LINE によるメッセージ受付

LINE Messaging API を利用し，Webhook 経由でユーザーからのテキストメッセージを受信する．

### 2. AI による自然言語解析

OpenAI API を利用し，自由記述のメッセージから用件や日付，時間などの情報を抽出し，JSON 形式のデータへ変換する．

### 3. タスクの振り分け

解析結果に応じて処理を振り分け，業務内容に対応するハンドラーを呼び出す．複数のタスクを含む入力についても，解析結果に基づく処理に対応できる構成を採用している．

### 4. シフト情報の登録・更新

Google Sheets API を利用し，月別のスプレッドシートにシフト情報を登録・更新する．シフト希望，シフト調整，確定シフトを別シートで管理する構成である．

### 5. ユーザー管理・利用制御

LINE のユーザー ID を用いてユーザー情報を管理する．初回利用時のユーザー登録と，登録状態（確認中・有効・無効）に応じた利用制御を実装している．

※ 各機能の実運用上の動作確認は引き続き進めている．

### 各コンポーネントの役割

| コンポーネント | 役割 |
|---|---|
| `LINE/app.py` | Webhook の受信，ユーザー登録・利用状態の確認，処理の呼び出し，返信 |
| `AI/ai_parser.py` | OpenAI API を利用した自然言語解析と JSON への変換 |
| `AI/dispatcher.py` | 解析結果に応じた処理の振り分け |
| `AI/handlers/` | シフト登録・変更、欠勤・遅刻連絡など，業務別の処理 |
| `Spreadsheet/spreadsheet.py` | Google Sheets API との連携，シフト情報とユーザー情報の管理 |
| `Config/` | API 認証情報や環境変数，依存ライブラリの管理 |

## 設計上の工夫

### 1. 自然言語を前提とした入力インターフェース

専用フォームへの入力を前提とせず，スタッフが日常的に利用する LINE から自由記述で連絡できる構成としている．入力形式を厳密に統一しなくても情報を扱えるよう，AI による解析処理を組み込んでいる．

### 2. 解析と業務処理の分離

自然言語解析を `ai_parser.py`，処理の振り分けを `dispatcher.py`，個別の業務処理を `handlers/` に分離している．
これにより，入力の解釈方法と業務ルールを独立して変更しやすい構成を目指す．

### 3. JSON を介したモジュール間連携

AI の解析結果を JSON 形式の中間データとして扱うことで，解析処理と業務処理の依存関係を抑えている．各ハンドラーが構造化されたデータを受け取る設計にすることで，機能の追加・変更を容易にすることを目指す．

### 4. データアクセス処理の集約

Google Sheets API との連携処理を `spreadsheet.py` に集約している．業務ロジックとデータアクセス処理を分離することで，シート構造の変更や将来的なデータベースへの移行に対応しやすい設計としている．

### 5. ユーザー状態に基づく利用制御

LINE ユーザー ID をもとにユーザー情報を管理し，管理者による状態変更を通じて利用を制御する仕組みを実装している．

## データ管理

### ユーザー情報

`ShiftBot_Users` スプレッドシートで管理する．

| 項目 | 内容 |
|---|---|
| `user_id` | LINE ユーザー ID |
| `LINE表示名` | LINE プロフィールから取得した表示名 |
| `名前` | スタッフ名 |
| `状態` | 確認中・有効・無効 |

### シフト情報

月別スプレッドシートに，以下のシートを設けて管理する．

- **シフト希望**：スタッフから提出された希望シフト
- **シフト調整**：希望をもとにした調整用シフト
- **確定シフト**：確定したシフト
