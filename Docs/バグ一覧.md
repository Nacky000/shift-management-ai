## メモ

- LINEユーザー自動登録・状態別の利用制限は `app.py` に組み込み済み。ただし、実運用テストは未完了。
- 月別Spreadsheetへのシフト登録とセル色分けは基本動作を確認済み。
- シフト変更は、既存シフトの取得と変更申請のSpreadsheetへの記録まで実装済み。申請の確認後にシフト表へ反映する処理・運用は未確認。
- シフト変更申請では、変更理由（`reason`）と変更後のシフトに付けるメモ（`memo`）を分けて保存する。
- シフト変更時は、指定されていない時刻を既存の値で維持する設計。
- 欠勤・遅刻では、日付が省略された場合に自動で今日の日付を補完せず、`date: null` のまま扱う。
- 欠勤・遅刻の元メッセージを保存するための「送信文」列は定義済み。ただし、実際の保存処理は確認が必要。
- OpenAI APIは基本動作を確認済み。ただし、現在はAPIクレジットの不足により、継続利用には追加のクレジット確認・補充が必要。
- 日付解決処理（`date_resolver.py`）とdispatcherへの組み込みは実装済み。基本テストも通過済み。
- `date_resolver.py` の `kind: "day"` は現状、翌月の日付として解決する。
- 月別Spreadsheetは現状、手動作成を前提としている。
- `memo` の自由記述保存・読み出しや `question` の検索機能は、今後の実装・確認対象とする。
- 未確認の機能は、基本実装が済んでいても実運用テスト完了までは完了扱いにしない。
