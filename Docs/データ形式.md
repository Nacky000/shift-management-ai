# データ形式

## シフト登録（schedule）

### データ例

```json
{
  "type": "schedule",
  "date": "2026-06-10",
  "start_time": "18:00",
  "end_time": "22:00",
  "memo": ""
}
```

### AI入力例

入力：

```text
6/10 18-22
```

出力：

```json
{
  "type": "schedule",
  "date": "2026-06-10",
  "start_time": "18:00",
  "end_time": "22:00",
  "memo": ""
}
```

`user_id` とスタッフ名は、原則としてAI出力に含めず、LINEのユーザー情報とスタッフ管理シートから取得する。

---

## シフト変更（change）

### AI入力例

入力：

```text
10日は20時からです
```

出力：

```json
{
  "type": "change",
  "date": "2026-06-10",
  "new_start_time": "20:00"
}
```

変更対象の既存シフトを特定し、指定されていない終了時刻などの情報は勝手に変更しない。

---

## 自由記述を含むシフト登録（schedule）

入力：

```text
10日は19時以降ならいつでも大丈夫です
```

出力：

```json
{
  "type": "schedule",
  "date": "2026-06-10",
  "start_time": "19:00",
  "end_time": null,
  "memo": "19時以降ならいつでも"
}
```

`end_time` が `null` の場合は終了時刻未指定として扱う。確定シフトに登録する際の扱いは、運用ルールに従う。

---

## 遅刻連絡（late）

入力：

```text
15分ほど遅れます
```

出力：

```json
{
  "type": "late",
  "reason": "",
  "minutes": 15
}
```

---

## 欠勤連絡（absence）

入力：

```text
体調不良のため休みます
```

出力：

```json
{
  "type": "absence",
  "reason": "体調不良"
}
```

---

## AIが判定できなかった場合（unknown）

入力：

```text
来週金曜遅めから
```

出力：

```json
{
  "type": "unknown",
  "message": "開始時間が特定できません"
}
```

---

## 共通ルール

- `type` は `dispatcher.py` が処理できる名称に統一する。
- 日付は `YYYY-MM-DD`、時刻は `HH:MM` 形式とする。
- AIが判定できない情報は推測で補わず、`unknown` または確認メッセージで対応する。
- `user_id` とスタッフ名は、LINEの送信者情報・スタッフ管理シートを基に補完する。
- 日付の年が省略された場合は、システムで定めた基準日・対象年月のルールに従って補完する。
- 既存シフトの変更では、指定されていない項目を上書きしない。
